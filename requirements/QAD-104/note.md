# Requirement questions

- [ ] Q1 — QAD-104 AC-01 requires "Do not treat the HTML summary alone as complete failure details; merge the detailed per-file results in the same zip by testId". It does not say on which page, or in what form, the merged failure details are visible. QAD-105 AC-02 says the original HTML report is embedded when there is a bundle, and AC-03 shows Test details only for runs without a bundle. Please confirm where the merged failure details (for example the error message) can be observed after a files-format push. This blocks scenarios for the files-format merge rule, but not the scenario that the files format is accepted.
- [ ] Q2 — QAD-104 AC-02 says "identify the file-level suite of the JSON reporter by title == file, and do not lose the feature title just because an ordinary describe suite also has a file". It does not say what the feature title is: the title of the file-level suite (that is, the file name) or some other text. The group titles in QAD-105 AC-03 also depend on it. Please confirm the value of the feature title and where it is shown. This blocks the feature-title scenarios.
- [ ] Q3 — QAD-104 AC-02 does not say what text Result shows in Test details, nor the unit and format of Duration (for example milliseconds or seconds). The current scenarios only assert that the values match what was pushed, not the exact display text. The assertions can be strengthened after confirmation. This does not block the current scenarios.
- [ ] Q4 — QAD-104 AC-03 says "Pushing the same report again replaces the records of the same run", but does not say how "the same run" is determined, nor which data is updated when a re-pushed report has changed content. The current scenarios only push the exact same report twice and check that nothing is duplicated. This blocks the "replace" scenarios.
- [ ] Q5 — QAD-104 AC-05 does not say how the endpoint responds when the bearer ingest token is missing (status code or message). The current scenarios only assert that the push is not accepted and no run is added. This does not block the current scenarios.
