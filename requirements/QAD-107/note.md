- [ ] Q1 — The README and parser notes say a missing items is not counted for adoption, but the implementation accepts an explicit generated; no items but generated>0 increases the denominator. QAD-107 AC-03 is limited to logs that also omit generated; other combinations need clarification and must not be generalized.
- [ ] Q2 — AC-02 only gives the ratio formulas. It does not say whether Adoption and Unchanged adoption are shown as percentages or decimals, nor how many decimal places (for example 60% or 60.0%). The current scenarios only assert the value, for example 60%, and require no particular number of decimal places. This does not block the scenarios; once the format is decided, they should assert the exact text. Source: QAD-107 AC-02.
- [ ] Q3 — AC-03 says "can still have cost, tokens", but the AC does not say where or how the AI page shows cost and tokens, nor any observable place outside the AI page. No observable assertion can be written, so no scenario is generated for that part. Source: QAD-107 AC-03.
- [ ] Q4 — AC-05 says "filtered by the date window", but does not say which time of the log the window compares (for example the log time or the run time). Scenario 06 uses "happened 3 days ago / 20 days ago", which is far from the 7-day and 30-day boundaries, so this does not block it. Source: QAD-107 AC-05.
